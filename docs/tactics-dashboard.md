# 自动踢球交接状态

球员卡片新增 `kick_control`（执行请求/后端接受/阻止/失败/取消失败）和 `auto_kick`（普通进攻接近、对齐、请求、冷却、受阻）的说明。显示请求已持续时间、剩余 1.2 秒预算、冷却剩余时间、最近退出原因、朝向/站位误差和准备点。计时使用仿真时间，从首次请求意图开始；实际启动可能更晚。后端接受不表示底层已经出脚或触球。旧回放缺少字段时显示未记录，不补造状态。守门员显示独立清球策略，不套用普通进攻的准备条件。

普通进攻进入距离 0.55 米、退出距离 0.75 米，进入朝向误差不超过 20°，持续误差不超过 35°；进入须位于球后准备点 0.15 米内且球在身体前方。单次请求达到 1.2 仿真秒后的首个控制帧取消，实际停止受帧间隔和 SDK 调用影响；退出后冷却 0.5 仿真秒；观测有效性、球路和接近检查继续生效。这些是待实测参数，不代表 SDK 的物理出脚阈值。本次不新增球路受阻兜底或门柱脱困。
