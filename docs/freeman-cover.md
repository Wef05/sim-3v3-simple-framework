# 自由人协防

正常比赛保留 FREEMAN 角色，内部在进攻接应和协防间切换。我方可行动队员确定均不能抢先时协防，有人确定抢先时接应；未知值按位置方向回退。罚下/倒地/模式未就绪不参与全队比较，无定位但其余条件可行动仍保留未知。速度未估计、窗口内无可达点及对手观测不完整不声称抢先结果确定。

未知时：门前大禁区立即协防；我方半场除明确远离球门外协防；对方半场在两秒趋势进入我方半场且朝己方球门移动时协防。方向通过球→己方球门的速度投影判断，阈值 0.2 m/s；使用当前估计速度幅值，未知不冒充静止。球位失效回预设防守位。进入立即，安全持续 0.6 仿真秒退出；角色/阶段切换及时间回退清除迟滞。

优先使用现有 calculate_block_point；只有朝己方门移动、保守到达时间含余量、球路接触早于对方预计触球、实体直线路径可走时才接触封堵。此意图关闭避球，保持面向、直线路径；新障碍仍由导航停车保护。未知对手触球时间不承诺拦球。几何模型不包含未来敌人变向或实际触球保证。

其余情况站到威胁源→己方门线上（优先预计对手拿球点，否则有效当前球位），不因计算无解停止。复用 SUPPORT_DIST_M=3 m，最多沿线 65%；场内边距/守门路径间距 0.9 m。协调层在收齐意图后对守门员目标路径让位，取消受影响的直接封堵承诺。所有移动保持实体避障；不会改变守门员职责、进攻手选择及重启策略。

遥测 freeman_cover 保存 mode/reason/race/strategy/source/target、方向有效性及封堵验算时间；看板卡片显示，协防期间不绘制进攻接应区域。旧回放兼容。阈值是未标定的初值，单场短测不证明战术收益。

验证：checks/test_freeman_cover.py 覆盖三态、位置方向、未知、暂停回退、阶段角色切换、对方先触球、障碍拒绝及守门路径让位；checks/test_dashboard_guard.cjs 增加真实卡片新旧数据验证。完整基线与变更后测试均记录，基线缺少 checks.goalkeeper_replay_cases 导致一项导入错误，未修改或掩盖。
