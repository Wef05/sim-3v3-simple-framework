# 自由人射门通道避让

## 行为与实现

本任务基于 `origin/MAIN` 的 `e8b4d9d`，分支 `codex/freeman-shot-clearance`，工作区 `/Users/limingzhe/.codex/worktrees/freeman-shot-clearance/sim-3v3-simple-framework`。

整队决策使用本帧角色分配中的 ATTACKER 及同帧队友位置，与敌方门柱 `(field.length/2, ±field.goal_width/2)` 构成闭三角形。自由人目的地必须距离这个闭三角形至少 0.38 m（机器人半径 0.25 m + 球半径 0.11 m + 到达误差 0.02 m）。角色切换或没有有效 attacker 时当帧替换/清空该约束；不使用球位置冒充 attacker。

保留原有球距离、对手距离、场地、门线及半圆/象限限制。圆角外扩边界由平行线段与顶点圆弧组成，补充投影和两两交点后统一判断可行性，仍求连续区域中的最近点。退化三角形按线段距离处理。无可行点则停止。看板直接读取遥测中的三角形与余量，显示紫色排除区并从绿色可选区扣除；旧回放缺失字段时明确提示。

改动文件：`src/utils/free_position.py`、`src/player.py`、`src/param.py`、`tools/tactics_dashboard/dashboard.js`；新增 `checks/test_free_position.py` 与 `checks/test_dashboard_freeman.cjs`。

本改动约束战术目标，不保证运动控制器路径或其修正后的目标全程避让射门通道。无可行点停止也不能保证当前身体已离开通道。没有新增依赖或更改角色分配算法。
